## 3. Heightfield Determinism & Canonical Hashes
To eliminate compiler-specific and architecture-specific precision variance between x86-64 and MIPS Allegrex (PSP), all procedural trigonometry in `src/physics/Terrain.cpp` was unified to `double` math functions (`sin`, `cos`, `fabs`) with intermediate variables stored as `double`, returning a single `(float)` cast at function exit.

### 3.2 Highway Floating-Point Analysis
The prior discrepancy on `highway` was caused by `sinf(x * 0.005f)` yielding slightly different least-significant mantissa bits under different optimization flags (`-O2` vs fast-math vs x87/SSE registers). Upgrading `highway` to pure `double sin((double)x * 0.005)` stabilizes the computation so both GCC and Clang produce bit-identical 64-bit IEEE 754 representations prior to truncation to `(float)`.

## 4. Vehicle ID Canonicalization: `[fingerscrew]` -> `[screwfinger]`
1. **Config:** The section header in `config/vehicles.cfg` was renamed from `[fingerscrew]` to `[screwfinger]`.
2. **Provenance:** `docs/params.csv` was updated to map `VEHICLE_UNLOCK_COST_SCREWFINGER,300000,extracted (1.30.0 @ 0x0f8755)`.
3. **Save Migration:** In `src/core/PlayerInfo.cpp` (`PlayerInfo::Load`), an automatic migration was implemented:
   - When iterating over saved vehicle slots, if `idHash == 0xDC088A10` (FNV-1a for `"fingerscrew"`), it is migrated to `0xB61B2D9E` (FNV-1a for `"screwfinger"`).
   - If a slot for `"screwfinger"` already exists, upgrades and unlock status are merged via `fmaxf()`.
   - `sDirty = true` is flagged so subsequent autosave commits the migrated canonical hash to `save.bin`.
4. **Verification:** Sub-test 8 was added to `tools/test_save.cpp` to verify that saves with `0xDC088A10` load properly, migrate to `0xB61B2D9E`, and persist canonical state.
