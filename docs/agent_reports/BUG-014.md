# Bug Fix Report: BUG-014

## 1. Описание дефекта
- **ID:** BUG-014
- **Severity:** P0 (Crash / Instant Death / Ground Penetration)
- **Файл и строка:** `src/core/Game.cpp:263` (anchor: `b2Vec2 startPos(0.0f, 2.5f);`)
- **Проявление:** Жестко захардкоженная координата точки старта `(0.0f, 2.5f)` приводила к тому, что на трассах с высотой грунта в нуле $h(0) > 1.6$ м колеса и шасси машины спавнились глубоко в толще геометрии рельефа. На таких трассах, как `nuclear` ($h(0)=3.25$ м), `rainbow` ($h(0)=3.20$ м), `volcano` ($h(0)=2.99$ м), `mountain` ($h(0)=2.60$ м), `rollercoaster` ($h(0)=2.54$ м), `beach` ($h(0)=2.46$ м), `haunted` ($h(0)=2.36$ м), машина мгновенно погибала («Driver Down») от удара о грунт на шаге 0, проваливалась сквозь полигоны либо катапультировалась от взрывной депенетрации Box2D.

## 2. Корневая причина (Root Cause)
В функции `Game::StartRace()` позиция `startPos` была задана константой `b2Vec2(0.0f, 2.5f)`. Реальная высота рельефа в нуле колеблется от $-0.33$ м (`junkyard`) до $+3.25$ м (`nuclear`). Кроме того, разные типы автомобилей обладают различными радиусами колес (от $0.26$ м у Minibike до $0.65$ м у Monster Truck) и вертикальными оффсетами осей (от $-0.30$ м до $-0.65$ м), а трассы с потолком (`cave`, `arcticcave`) накладывают ограничение сверху, чтобы голова водителя не разбивалась о потолок при спавне.

## 4. Минимальный фикс
В `src/core/Game.cpp`:
```cpp
    float rR = (vConfig && vConfig->rear_wheel_radius > 0.0f) ? vConfig->rear_wheel_radius : (vConfig ? vConfig->wheel_radius : 0.40f);
    float rF = (vConfig && vConfig->front_wheel_radius > 0.0f) ? vConfig->front_wheel_radius : (vConfig ? vConfig->wheel_radius : 0.40f);
    float maxR = (rR > rF) ? rR : rF;
    float offYR = vConfig ? vConfig->rear_wheel_offset[1] : -0.50f;
    float offYF = vConfig ? vConfig->front_wheel_offset[1] : -0.50f;
    float minOffY = (offYR < offYF) ? offYR : offYF;
    float absMinOffsetY = fabsf(minOffY);

    float groundH = mTerrain ? mTerrain->GetHeightAtX(0.0f) : 0.0f;
    float startY = groundH + maxR + absMinOffsetY + 0.25f;

    if (mTerrain && mTerrain->HasCeiling()) {
        float ceilH = mTerrain->GetCeilingHeightAtX(0.0f);
        float headOffY = vConfig ? vConfig->driver_head_offset[1] : 0.50f;
        float headR = vConfig ? vConfig->driver_head_radius : 0.24f;
        float maxAllowedY = ceilH - headOffY - headR - 0.5f;
        if (startY > maxAllowedY) {
            startY = maxAllowedY;
        }
    }
    b2Vec2 startPos(0.0f, startY);
```
Также `mCameraY = startY;` для исключения стартового скачка камеры.
