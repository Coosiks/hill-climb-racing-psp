## 2. Race Summary & Economy Tracking Architecture

In `src/core/Game.h` and `src/core/Game.cpp`:
- **State Tracking:**
  - `mRaceCollectedCoins`: Physical pickups on terrain, multiplied by stage coin multiplier.
  - `mRaceTrickBonusCoins`: Stunt earnings (Air Time, Wheelie, Backflip, Frontflip).
  - `mRaceDistanceBonusCoins`: Reserved for stage milestone distance bonuses.
  - `mSessionCoins = mRaceCollectedCoins + mRaceTrickBonusCoins + mRaceDistanceBonusCoins`.
  - `mIsNewRecord`: Boolean flag evaluated during `CommitRaceResults()`.
- **Commit & Persistence Logic:**
  ```cpp
  void Game::CommitRaceResults() {
      PlayerInfo::AddCoins(mSessionCoins);
      mIsNewRecord = false;
      if (mCurrentStage >= 0 && mCurrentStage < Config::StageCount) {
          uint32_t stageHash = PlayerInfo::HashId(Config::Stages[mCurrentStage].id);
          int curBest = PlayerInfo::GetStageRecord(stageHash);
          if ((int)mMaxDistance > curBest) {
              mIsNewRecord = true;
              PlayerInfo::SetStageRecord(stageHash, (int)mMaxDistance);
          }
          if (mCurrentStage < STAGE_COUNT && (int)mMaxDistance > PlayerInfo::HighScores[mCurrentStage]) {
              PlayerInfo::HighScores[mCurrentStage] = (int)mMaxDistance;
          }
      }
      PlayerInfo::Save();
  }
  ```

## 3. UI Implementation: Game Over Screen & Garage Cards

### 3.1 `RenderGameOver()` Layout
- Header banner dynamically colors based on failure cause:
  - Driver Down: Red (`0xFF2222C0` in ABGR).
  - Out of Fuel: Orange (`0xFF22A0C0` in ABGR).
- Distance display with dynamic `NEW RECORD!` badge rendered adjacent to distance when `mIsNewRecord` is true.
- Detailed coin breakdown:
  - `COINS: +<N>` in cyan (`0xFF00E5FF`).
  - `TRICKS: +<M>` in neon green (`0xFF55FF55`).
  - `TOTAL COINS: <balance>` in silver (`0xFFE0E0E0`).
- Interactive prompts: `[X] RETRY` and `[O] GARAGE`.
