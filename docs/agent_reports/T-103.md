# Agent Report: T-103 (physics) — Inverted Air Control Fix & Regression Test

## 1. Goal & Context
In the original Hill Climb Racing physics model (Box2D, y-up):
- **Throttle (Gas)** in the air applies positive torque (CCW rotation) -> tilts car nose up and backward, producing a **Backflip**.
- **Brake** in the air applies negative torque (CW rotation) -> tilts car nose down and forward, producing a **Frontflip**.

Previously, the sign of `AIR_PITCH_TORQUE` was inverted (`-AIR_PITCH_TORQUE` for gas, `+AIR_PITCH_TORQUE` for brake), causing the car to nose-dive when pressing gas in the air.

## 2. Changes Made
1. **`src/physics/PlayerCar.cpp`:**
   - In throttle branch: changed `ApplyTorque(-AIR_PITCH_TORQUE, true)` to `ApplyTorque(AIR_PITCH_TORQUE, true)` (+torque, CCW, nose-up/backflip).
   - In brake branch: changed `ApplyTorque(AIR_PITCH_TORQUE, true)` to `ApplyTorque(-AIR_PITCH_TORQUE, true)` (-torque, CW, nose-down/frontflip).
   - Corrected comments to clearly document CCW = Backflip, CW = Frontflip.
   - Preserved `AIR_PITCH_TORQUE = 10.0f` without arbitrary retuning (marked TODO-TUNE awaiting 60 FPS reference video).
2. **`CMakeLists.txt` & `.github/workflows/build.yml`:**
   - Added automated regression test `test_aircontrol` (`tools/test_aircontrol.cpp`).
   - Integrated `test_aircontrol` execution into CI verification step.
3. **Release Errata:**
   - Appended errata note to GitHub Release `v0.1.0-beta.1` notes.

## 3. Regression Test Results (`test_aircontrol`)
The test runs 180 simulation steps (3.0 seconds at 60 Hz) under zero-gravity airborne conditions:
- **Test 1 (Throttle held):**
  - Final angle: **+12.473 rad** (+714.6°, positive CCW rotation).
  - Flips awarded: **2 Backflips** (at $t=2.00$s and $t=2.95$s).
  - Status: **PASS**.
- **Test 2 (Brake held):**
  - Final angle: **-12.147 rad** (-696.0°, negative CW rotation).
  - Flips awarded: **1 Frontflip** (at $t=2.05$s).
  - Status: **PASS**.
