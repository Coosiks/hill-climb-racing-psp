## 1. Problem & Architecture Overview
In Hill Climb Racing, the driver's head is mounted to the vehicle chassis via an angular revolute joint with elastic angular limits and a restoring spring motor. This causes characteristic inertial head swaying over bumps, hill climbs, and hard landings.
Crucially, when the driver's head strikes solid terrain (`CAT_TERRAIN`), it triggers an instant catastrophic crash (`DRIVER DOWN!`) leading to immediate Game Over and results commitment. Conversely, contacts with collectible item sensors (coins and fuel) must never trigger driver death.
On death, the neck joint does not detach; rather, its motor torque weakens, producing a limp ragdoll neck that remains bound within physiological angular limits.

## 2. Implementation Details

### A. Driver Head & Fixture Collision Filtering (`src/physics/PlayerCar.cpp`)
- **Body & Shape:** Dynamic body created at `startPos + driver_head_offset` with `b2CircleShape` radius `driver_head_radius` (0.24m).
- **Collision Filter:**
  - `categoryBits = CAT_DRIVER`
  - `maskBits = CAT_TERRAIN | CAT_ITEM`
  - Eliminates unwanted self-collision against `CAT_CHASSIS` and `CAT_WHEEL` while ensuring responsiveness to ground collisions and item collection.

### B. Revolute Joint & PD Spring Motor (`src/physics/PlayerCar.cpp`)
- **Joint Definition:** `b2RevoluteJointDef` connecting `mChassis` and `mDriverHead` at neck anchor `headPos + (0.0f, -0.15f)`.
- **Limits:** `enableLimit = true`, `lowerAngle = -0.60f` rad, `upperAngle = +0.60f` rad.
- **PD Spring Controller:** In `PlayerCar::Update(dt)`:
  ```cpp
  if (mNeckJoint) {
      float neckAngle = mNeckJoint->GetJointAngle();
      float kSpring = 10.0f;
      mNeckJoint->EnableMotor(true);
      mNeckJoint->SetMotorSpeed(-kSpring * neckAngle);
      mNeckJoint->SetMaxMotorTorque(15.0f);
  }
  ```
- **Limp Ragdoll on Death:** In `PlayerCar::Kill()` and in dead state updates:
  ```cpp
  if (mNeckJoint) {
      mNeckJoint->EnableMotor(true);
      mNeckJoint->SetMotorSpeed(0.0f);
      mNeckJoint->SetMaxMotorTorque(0.5f);
  }
  ```

### C. Driver Down Trigger & Sensor Immunity (`src/physics/PhysicsWorld.cpp`)
- In `PhysicsWorld::BeginContact`:
  ```cpp
  if ((catA == CAT_DRIVER && catB == CAT_TERRAIN) ||
      (catB == CAT_DRIVER && catA == CAT_TERRAIN)) {
      if (!fixA->IsSensor() && !fixB->IsSensor()) {
          if (mListener) {
              mListener->OnDriverDown();
          }
      }
  }
  ```
- Verifies that solid terrain contact triggers `OnDriverDown()` while item sensor overlap preserves driver life.
