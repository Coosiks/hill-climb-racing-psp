# Agent Report: Tasks T-043 & T-044 (audio/tools) — Offline Audio Pipeline, Engine Loop Pitch Modulation [0.50, 2.00] & SFX

**Task IDs:** T-043, T-044  
**Component:** Audio / Offline Tools / Engine Sound Modulation / Mixer  
**Date:** 2026-11-14  

---

## 1. Problem & Context
On Sony PlayStation Portable (PSP) hardware, runtime decoding of compressed `.ogg` streams via `stb_vorbis` is memory-heavy and burns significant CPU cycles on the single-core MIPS Allegrex processor. Furthermore, Hill Climb Racing requires authentic vehicle engine sound looping with continuous, responsive pitch modulation based on throttle input and wheel rotational velocity, clamped between $[0.50, 2.00]$.

---

## 2. Technical Implementation

### A. Offline Preprocessing Pipeline (`tools/convert_assets.py` — T-043)
- Added offline audio conversion function `convert_audio_to_wav(data_or_path, dst_wav_path, target_rate=22050)`:
  - Automatically processes `.ogg`, `.mp3`, and `.wav` audio files from APK or asset directory.
  - Converts audio into canonical **16-bit PCM mono 22050 Hz** uncompressed `.wav` files.
  - Utilizes system CLI tools (`ffmpeg` or `oggdec` from `vorbis-tools`) with seamless fallback.
  - Added CLI flag `--no-audio` to bypass audio processing during rapid asset builds.

### B. High-Performance Runtime WAV Loader (`src/audio/AudioEngine.cpp` — T-044)
- Implemented `AudioEngine::LoadWav` and `AudioEngine::LoadWavFromMemory`:
  - Parses standard RIFF/WAVE headers and extracts 16-bit uncompressed PCM samples.
  - Completely strips runtime dependency on `stb_vorbis` from the PSP target build, saving code size and dynamic heap allocations.
  - Retains transparent fallback to `.ogg` on PC targets when `.wav` files are absent.

### C. Engine Audio Loop & Fixed-Point 16.16 Resampler
- **Pitch Modulation Curve:**
  - Idle throttle: `targetPitch = 0.60f`
  - Active throttle: $p = 0.60f + \text{rev} \times 1.40f$, strictly clamped to $[0.50f, 2.00f]$.
  - Smooth exponential interpolation: `mEnginePitch += (mTargetPitch - mEnginePitch) * (8.0f * dt);`
  - When out of fuel or driver dead: engine sound is muted and pitch targets $0.50f$.
- **Fixed-Point Resampler:**
  - Sample rate adaptation ratio: $\text{rateRatio} = \frac{\text{sampleRate}}{44100.0f}$
  - Phase step calculation: `stepFP = (unsigned int)(mEnginePitch * rateRatio * 65536.0f);`
  - Sample loop index: `sIdx = enginePosFP >> 16`, strictly guarded by `maxPosFP` wrapping, guaranteeing zero buffer overflows.

### D. Audio Mixer, Volume Controls & Pause Semantics
- Supported sound effects: `SFX_COIN`, `SFX_CRACK`, `SFX_REFUEL`, `SFX_CLICK`, `SFX_UPGRADE`.
- Independent volume controls `SetMusicVolume(float)` and `SetSFXVolume(float)` clamped to $[0.0, 1.0]$.
- Complete pause semantics (`PauseAll()` / `ResumeAll()`): suspends audio output buffer filling and freezes sample phase accumulators without clicks or pops.
- Headless safety: fully safe operation on CI test runners without physical audio hardware.
