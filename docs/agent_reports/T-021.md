## 1. Цели и задачи T-021

1. **Реализация висячих мостов без динамических аллокаций:**
   - Статический пул мостов: `MAX_ACTIVE_BRIDGES = 4`, `MAX_BRIDGE_PLANKS = 12`.
   - Дощечка (plank): динамическое тело `b2Body` (`b2_dynamicBody`) с прямоугольной формой `b2PolygonShape` ($1.2\text{ м} \times 0.2\text{ м}$), плотностью $1.5$, трением $0.70$, категорией `CAT_TERRAIN` и маской `CAT_CHASSIS | CAT_WHEEL`.
2. **Шарнирное сочленение дощечек:**
   - Соединение дощечек через `b2RevoluteJoint` с ограничением угла вращения `lowerAngle = -0.25f` rad ($-14.3^\circ$), `upperAngle = +0.25f` rad ($+14.3^\circ$).
   - Левый конец соединяется с левым статическим анкером чанка (`slot.body`), правый конец — с правым анкером (`slot.body`).
   - Ограничения углов шарниров предотвращают провисание моста и складывание «гармошкой» под весом автомобиля.
3. **Генерация расщелины и спавн моста:**
   - Для трасс с `has_bridges == 1` (`Forest`) при завершении генерации чанка (`chunkIndex % 4 == 1`, начиная с чанка 1) создается расщелина с мостом длиной 12 метров (10 дощечек по 1.2 м) от $x_0 = \text{chunkStart} + 9.0$ м до $x_1 = \text{chunkStart} + 21.0$ м.
   - Под мостом в `GetHeightAtX` грунт плавно опускается по синусоиде на глубину до 3.5 метров, образуя овраг.
4. **Жизненный цикл и нулевые утечки тел (Zero Leaks):**
   - При выгрузке чанка (`UnloadChunk`) вызывается `DestroyBridgeForChunk(chunkIndex)`, который удаляет все шарниры (`DestroyJoint`) и тела дощечек (`DestroyBody`), освобождая слот в пуле.
   - В деструкторе `~Terrain()` вызывается `DestroyAllBridges()`.
   - Общее количество тел в `b2World` при заезде на 2000 м остается в фиксированном пуле.
5. **Батчинг рендеринга:**
   - Отрисовка дощечек активных мостов через `Renderer2D::DrawSprite` с текстурой `BridgeWoodBlock.png` с поворотом на физический угол каждой дощечки `plank->GetAngle()`.

## 2. Физическая модель висячего моста

### Параметры конструкции:
- Длина пролета: 12.0 м
- Число дощечек: 10
- Размеры дощечки: ширина 1.20 м, толщина 0.20 м
- Масса дощечки в Box2D: $\approx 1.2 \times 0.2 \times 1.5 = 0.36$ кг
- Шарниры: 11 штук `b2RevoluteJoint`
- Лимиты шарниров: $[-0.25, +0.25]$ rad
- Статический прогиб под гравитацией ($g = -10$ м/с²): $\approx 0.29$ м в центральной точке

       \_________________ Расщелина (3.5м) __________________/

## 3. Верификация жизненного цикла тел (Zero Leaks)

- До создания моста: $N$ тел
- При создании моста: $N + 10$ тел
- При выгрузке чанка (`UnloadChunk`): $N$ тел
- Все 11 шарниров и 10 тел гарантированно уничтожаются через Box2D API без утечек памяти.
