## 1. Problem & Architecture Overview
In Hill Climb Racing, skillful vehicle maneuvering is rewarded with immediate coin bonuses and HUD celebration banners:
1. **Flips (Backflip / Frontflip):** Full $360^\circ$ airborne rotations.
2. **Air Time:** Extended airborne flight ($\ge 1.0\text{ s}$), rewarding points proportional to flight duration upon a successful alive landing.
3. **Wheelie:** Driving balanced solely on the rear wheel with the front wheel raised for $\ge 1.5\text{ s}$.

All trick rewards must credit the active run balance (`mSessionCoins`) and save to player progression upon race completion (`CommitRaceResults()`).

---

## 2. Implementation Details

### A. Dynamic In-Air & Ground Contact Tracking (`src/physics/PlayerCar.cpp`)
Added dedicated sensor queries:
- `IsRearWheelOnGround()` / `IsFrontWheelOnGround()`: filters solid `CAT_TERRAIN` contacts, ignoring sensor fixtures.
- `IsInAir()`: true if both wheels have zero non-sensor contacts with terrain.

### B. Air Time Bonus Suite
- Continuously increments `mAirTime` while `IsInAir()` is true.
- On landing transition (`mPrevInAir && !IsInAir()`):
  - If driver is alive and `mAirTime >= Config::Physics.air_time_threshold` (1.0s):
    - `int seconds = (int)floorf(mAirTime);`
    - `int bonus = seconds * (int)Config::Physics.air_time_bonus_rate;` (250 coins/sec).
    - Pending bonus popped via `PopAirTimeBonus(&airSec)`.

### C. Wheelie Bonus Suite
- Evaluates active wheelie condition:
  `!mIsDead && rearOnGround && !frontOnGround && angle > 0.08f && angle < 1.40f`
- While held, accumulates `mWheelieTime`.
- When ended (front wheel touches down or car flips):
  - If `mWheelieTime >= Config::Physics.wheelie_threshold` (1.5s):
    - `int seconds = (int)floorf(mWheelieTime);`
    - `int bonus = seconds * Config::Physics.wheelie_bonus_coins;` (500 coins base).
    - Pending bonus popped via `PopWheelieBonus(&wheelieSec)`.

### D. Game HUD & Economy Dispatch (`src/core/Game.cpp`)
In `Game::Update(dt)`:
- Queries `PopFlips()`, `PopAirTimeBonus()`, and `PopWheelieBonus()`.
- Credits awarded coins to `mSessionCoins`.
- Displays HUD banner (`"BACKFLIP!"`, `"FRONTFLIP!"`, `"AIR TIME!"`, or `"WHEELIE!"`) with `+<N> COINS` subtitle and plays coin SFX.

### E. Configuration Unification (`config/physics.cfg`, `Config.h`, `Config.cpp`)
Configured keys in `[rules]`:
- `air_time_bonus_rate = 250.0`
- `wheelie_threshold = 1.5`
- `wheelie_bonus_coins = 500`
- Verified in `tools/test_config.cpp`: `physics.cfg: 20 / 20 keys fully covered` (total keys: 73).
