## 2. Vendor Tree Pruning (`vendor/Box2D/`)
The following unused subtrees and files were removed from the git tree via `git rm -rf`:
- `vendor/Box2D/Documentation/` (manuals, Doxygen configuration, diagrams)
- `vendor/Box2D/HelloWorld/` (standalone console example)
- `vendor/Box2D/Testbed/` (OpenGL testbed harness, ImGui, GLUT dependencies)
- `vendor/Box2D/glew/` (bundled GLEW sources)
- `vendor/Box2D/glfw/` (bundled GLFW sources and windowing platform wrappers)
- `vendor/Box2D/premake4.lua` (legacy build generator script)

### Preserved Assets:
- `vendor/Box2D/Box2D/`: Core library headers and implementation sources containing the `b2WheelJoint` translation limits solver backport.
- `vendor/Box2D/LICENSE`, `License.txt`: Upstream zlib licenses.
- `vendor/Box2D/CMakeLists.txt`: Root configuration updated with `BOX2D_BUILD_EXAMPLES OFF`.
- `docs/VENDOR_PATCHES.md`: Full upstream patch documentation and legal attribution.
