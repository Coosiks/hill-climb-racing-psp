# Task Report: H17a — Stage Texture Path Resolution & Asset Audit

## 1. Problem Statement & Findings
1. **Broken Stage Texture Paths:**
   - Previous configuration in `config/stages.cfg` assumed generic naming patterns like `terrain-rollercoaster-ground.png`, `cave-ground.png`, `forest-ground.png`, etc.
   - When running on authentic assets extracted from APK 1.30.0, this resulted in 22 texture load errors across 15 stages.
   - 4 stages (`cave`, `rooftops`, `construction`, `ragnarok`) do not have dedicated ground textures in the original APK and require explicit fallback to `assets/terrain-ground.png`.
2. **Missing Automated Asset Audit:**
   - `tools/convert_assets.py` converted assets but did not assert 100% texture and audio coverage against `config/stages.cfg` and `config/vehicles.cfg`.

## 2. Changes Implemented

### 2.1 Stage Texture Path Resolution
- Resolved texture paths in `config/stages.cfg` to match actual APK files:
  - `cave`: `ground_texture = assets/terrain-ground.png`, `surface_texture = assets/terrain-cave-surface.png`
  - `mars`: `ground_texture = assets/mars-ground.png`, `surface_texture = assets/terrain-mars-surface.png`
  - `forest`: `ground_texture = assets/terrain-forest-ground.png`, `surface_texture = assets/terrain-forest-surface.png`
  - `rollercoaster`: `ground_texture = assets/terrain-rollercoaster.png`, `surface_texture = assets/terrain-rollercoaster-surface.png`
  - `night`: `ground_texture = assets/terrain-night.png`, `surface_texture = assets/terrain-night-surface.png`
  - `rooftops`: `ground_texture = assets/terrain-ground.png`, `surface_texture = assets/building-01-roof.png`
  - `junkyard`: `ground_texture = assets/terrain-junkyard.png`, `surface_texture = assets/terrain-junkyard-surface.png`
  - `construction`: `ground_texture = assets/terrain-ground.png`, `surface_texture = assets/construction-building1-roof.png`
  - `rainbow`: `ground_texture = assets/terrain-rainbow.png`, `surface_texture = assets/terrain-rainbow-surface.png`
  - `seasons`: `ground_texture = assets/terrain-seasons-spring.png`, `surface_texture = assets/terrain-seasons-spring-surface.png` (canonical spring base)

### 2.2 Canonical Asset Audit Pipeline
- Implemented `audit_assets` in `tools/convert_assets.py` verifying:
  - 28 Stages: both `ground_texture` and `surface_texture` in `.png` and `.tex` format.
  - 29 Vehicles: `body_texture`, `wheel_texture`, and `preview_texture` in `.png` and `.tex` format.
  - 28 Music tracks: verifying presence of audio tracks (.wav or .ogg).
- Added `--allow-missing` flag: default behavior exits with code 1 if any asset is missing.

### 2.3 Documentation
- Documented canonical `spring` variant and texture fallbacks in `docs/params.csv` and `docs/ROADMAP.md`.
