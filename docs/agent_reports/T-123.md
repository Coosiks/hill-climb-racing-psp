## 4. Viscous Mud Pools Physical Mechanics

### 4.1 Zone Detection
In `src/physics/Terrain.h`:
```cpp
inline bool Terrain::IsInMudZone(float x) const {
    if (!mStageConfig || mStageConfig->has_mud_pools == 0) return false;
    if (x < 15.0f) return false;
    float modX = fmodf(x, 60.0f);
    if (modX < 0.0f) modX += 60.0f;
    if (mStageType == STAGE_VOLCANO) {
        return (modX >= 20.0f && modX <= 34.0f);
    }
    return (modX >= 18.0f && modX <= 32.0f);
}
```

### 4.2 Force Integration
In `src/physics/PlayerCar.cpp`:
When a wheel contacts `CAT_TERRAIN` and `IsInMudZone(wheelPos.x)` evaluates to `true`:
- Opposing linear viscous drag: $\vec{F}_{\text{drag}} = -c_{\text{mud}} \cdot m \cdot \vec{v}$.
- Opposing angular braking torque: $\tau_{\text{drag}} = -\omega \cdot c_{\text{mud}} \cdot 2.0$.
- Chassis viscous deceleration: $\vec{F}_{\text{chassis}} = -c_{\text{mud}} \cdot m_{\text{chassis}} \cdot 15.0 \cdot \vec{v}_x$.
