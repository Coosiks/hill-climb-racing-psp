# H6: Verification of Test Targets & PSP stb_vorbis Zero-Footprint Status

## 1. Executive Summary
- **Purpose:** Audit and align test suite naming conventions with actual CMake targets and verify that `stb_vorbis.c` has zero runtime footprint in the Sony PSP target binary (`hcr.elf` / `EBOOT.PBP`).
- **Target Names Verification:** Confirmed 15 actual regression test binary targets built and executed in CMake and GitHub Actions CI without fabricated or truncated names.
- **Audio Decoding Status on PSP:** Confirmed that `stb_vorbis.c` is strictly excluded from PSP compilation via preprocessor directives and `Makefile` object lists. Zero vorbis decoding code or tables exist in `hcr.elf`.

## 3. Evidence: stb_vorbis Exclusion on PSP Target

### 3.1. Grep Check in `AudioEngine.cpp` and `Makefile`

```
$ grep -n "stb_vorbis" src/audio/AudioEngine.cpp Makefile
src/audio/AudioEngine.cpp:7:// Include stb_vorbis implementation only on non-PSP targets for fallback

src/audio/AudioEngine.cpp:116:    int sampleCount = stb_vorbis_decode_filename(filepath, &channels, &sampleRate, &decoded);
```

In `src/audio/AudioEngine.cpp`:
- Lines 5–9:
  ```cpp
  #if defined(__PSP__)
  #include "core/fpu.h"
  #else
  // Include stb_vorbis implementation only on non-PSP targets for fallback
  #include "stb_vorbis.c"
  #endif
  ```

- Lines 114–126:
  ```cpp
  #if !defined(__PSP__)
      int channels = 0;
      int sampleRate = 0;
      short* decoded = NULL;
      int sampleCount = stb_vorbis_decode_filename(filepath, &channels, &sampleRate, &decoded);
      ...
  #endif
  ```
- In `Makefile`: `stb_vorbis.o` is **absent** from `OBJS`.

### 3.2. Binary Section Sizes (`size hcr.elf`)

PSP binary `hcr.elf` built in CI runner environment:
```
   text    data     bss     dec     hex filename
 490752   23192 1166484 1680428  19a42c hcr.elf
```
- Total executable code (`.text`): 490,752 bytes (~479 KB)
- Initialized data (`.data`): 23,192 bytes (~22.6 KB)
- Uninitialized BSS (`.bss`): 1,166,484 bytes (~1.11 MB, includes static batch buffers and engine audio sample buffers)
- Stripped ELF size: 515,736 bytes
- Final `EBOOT.PBP`: 522,796 bytes
