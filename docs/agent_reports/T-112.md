# Agent Report: T-112 (core) — Cross-Platform Heightfield Determinism

## 1. Goal & Context
Hill Climb Racing tracks and future replay systems require cross-platform heightfield determinism:
- In `Terrain::GetHeightAtX`, terrain elevations are computed using compound trigonometric series (`cos` and `sin`) evaluated in `double` precision.
- Potential Risk: `double` floating-point math implementations can theoretically diverge between PC (`glibc` on x86_64) and PSP (`newlib` soft-float on 32-bit MIPS Allegrex) in the lowest significant bits (ULP), which could produce differing collision geometry, trajectories, or replay desynchronization.

## 2. Methodology & Instrumentation
1. **Hash Algorithm:** 64-bit FNV-1a hash (`FNV1a_64`) computed over contiguous buffers of IEEE 754 32-bit `float` elevations.
2. **Sampling Protocol:**
   - Evaluated across all 4 production stages: Countryside, Desert, Arctic, Moon.
   - Distance span: $X = 0.0\text{ m}$ to $X = 2,000.0\text{ m}$.
   - Sampling step: $\Delta X = 0.5\text{ m}$ (`TERRAIN_SEGMENT_STEP`).
   - Sample count per stage: $N = 4,001$ points ($16,004$ bytes per stage, $64,016$ bytes total).
3. **Execution Environments:**
   - **PC Reference:** Headless regression test `tools/test_terrain.cpp` compiled with GCC 13.3.0 on Ubuntu 24.04 (Linux x86_64, `glibc`).
   - **PSP Hardware Emulation:** Canonical `EBOOT.PBP` compiled with PSPSDK GCC 15.2.0 (`newlib` soft-float) executed on PPSSPP v1.20.4 in **PSP-1000 mode** (`PSPModel = 0`, 32 MB user RAM @ 333 MHz Allegrex MIPS).

## 4. Analysis & Decision on Quantization
- **Finding:** All 4,001 sampled vertices across all 4 stages are bit-for-bit identical between `glibc` and PSP `newlib` soft-float.
- **Quantization:** Per task specifications, because the raw `double` trigonometric evaluations already produce bit-exact identical IEEE 754 float values between PC and PSP, heightfield quantization is **not required** and was not applied. This preserves the decompiled mathematical formulas at 100% native fidelity without introducing artificial step artifacts or loss of precision.
