## 2. Reverse Engineering из libgame.so (1.30.0)

В ходе дизассемблирования `libgame.so` найдены структуры RTTI Itanium ABI и виртуальные таблицы классов генераторов трасс:
- `StageHighway`: vtable `@ 0x4044c0`, функция генерации `@ 0x148f0a`
- `StageCave`: vtable `@ 0x404700`, функция генерации `@ 0x148776`, смещение потолка `@ 0x14269e`
- `StageMars`: vtable `@ 0x404dc0`, функция генерации `@ 0x147626`
- `StageForest`: vtable `@ 0x4056c0`, функция генерации `@ 0x148b88`

Полный дамп ассемблерных листингов и адресов зафиксирован в файле `docs/bench/re_stage_generators_dump.txt`.

### Математические формулы генераторов:
```cpp
case STAGE_HIGHWAY: {
    // Fast undulating asphalt waves
    double w1 = 0.5 * sin((double)(t * 0.335f + 3.14159f) * 4.0);
    double w2 = 1.6 * sin((double)(t * 0.09178f + 3.14159f));
    double w3 = 1.6 * sin(0.5 * (double)(t * 0.11754f + 3.14159f));
    float k = clampf(t * 0.001f, 0.0f, 1.0f);
    double s = w1 * 0.4 + w2 * 0.6 + w3 * (0.5 + 0.5 * (double)k);
    return (float)s * 1.5f;
}

case STAGE_CAVE: {
    // Rocky floor with bumpy undulating profile
    double w1 = cos((double)(t / 17.0f));
    double w2 = sin((double)(t / 7.21f) + w1);
    double w3 = cos((double)(t / 185.0f));
    double w4 = (w3 + 1.5) * w2;
    double w5 = sin((double)t + cos((double)(t * 0.1265f)));
    double w6 = cos((double)(t / 200.0f)) * 0.2;
    double s = w4 * 0.5 + w5 * 0.35 + w6 * 0.8;
    return (float)s;
}

case STAGE_MARS: {
    // Martian terrain with craters and steep slopes
    float tm = x * 1.75f + 10.0f;
    double w1 = cos((double)(tm / 67.0f));
    double w2 = sin((double)(tm / 9.21f) + w1);
    double w3 = cos((double)(tm / 185.0f));
    double w4 = (w3 + 1.95) * w2;
    double w5 = sin((double)tm + cos((double)(tm * 0.1265f)));
    double s = w4 * 0.65 + w5 * 0.45;
    return (float)s * 1.4f;
}

case STAGE_FOREST: {
    // Rolling forest hills and bridge dips
    double w1 = sin((double)(t / 10.0f));
    double w2 = cos((double)(t * 0.215f));
    double w3 = cos((double)t + w2);
    double w4 = cos((double)(t * 0.515f));
    double s = w1 * 1.2 + w3 * 0.8 + w4 * 0.4;
    return (float)s;
}
```

## 3. Инвариант зазора потолка Cave

Потолок Cave рассчитывается функцией `GetCeilingHeightAtX(float x)`:
```cpp
float Terrain::GetCeilingHeightAtX(float x) const {
    float floorY = GetHeightAtX(x);
    if (!HasCeiling()) {
        return floorY + 20.0f;
    }
    float baseOffset = (mStageConfig && mStageConfig->ceiling_offset > 0.0f) ? mStageConfig->ceiling_offset : 6.5f;
    float t = x * 0.05f;
    float undulation = sinf(t * 1.15f) * 0.70f + cosf(t * 0.45f) * 0.40f;
    float ceilY = floorY + baseOffset + undulation;
    if (ceilY < floorY + 4.5f) {
        ceilY = floorY + 4.5f;
    }
    return ceilY;
}
```
Инвариант `ceilY - floorY >= 4.5f` строго гарантирован как аналитически (размах $6.5 \pm 1.1 = [5.4, 7.6]$ м), так и программным предохранителем `ceilY = floorY + 4.5f`.
