## 1. Objective & Context
Prepare the repository for public Beta release `v0.1.0-beta.1` under the clean-room reimplementation mandate:
1. Conduct pre-publish legal and secrets audit across the entire tree.

---

## 2. Summary of Changes
- **Legal & Sanitization:**
  - Audited full file tree. No copyrighted binaries (`libgame.so`, `hcr_1.0.5.apk`) or raw APK assets are tracked.
  - Excluded `assets/`, `assets_converted/`, `original_apk/`, `data/`, and build artifacts from git via `.gitignore`.
  - Added `.gitattributes` to enforce LF line endings and mark binary formats.
  - Replaced temporary packaging paths containing username references in `tools/package.py` with relative CLI-driven paths.
  - Replaced root XMB images (`ICON0.PNG`, `PIC1.PNG`) with clean, generated homebrew artwork.
- **Vendored Libraries:**
  - Migrated `external/` to `vendor/` (`vendor/Box2D/`, `vendor/stb/`) preserving official `LICENSE` files.
- **Configuration Engine:**
  - Moved default configuration files to `config/physics.cfg`, `config/vehicles.cfg`, `config/stages.cfg`.
  - Updated `src/core/Config.cpp` to look in `config/` first, falling back to `data/`.
- **Startup Protection:**
  - Added an informative error screen in `src/main.cpp` explaining the "Bring Your Own APK" model if assets are missing, avoiding crashes on both PSP and PC.
- **Build System:**
  - Created `CMakeLists.txt` for native PC build (`build-pc/hcr_pc`).
  - Updated PSP `Makefile` with `vendor/` includes and `src/core/Config.o`.
- **Reviewer Documentation:**
  - Created `docs/STATUS.md`, `docs/ROADMAP.md`, `docs/architecture.md`, `docs/build.md`, `docs/perf.md`.
