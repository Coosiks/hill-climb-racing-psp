# Agent Report: T-111 (tools+render) — Preprocessed Texture Pipeline & PSP Swizzled .tex Loader

## 1. Goal & Context
Prior to T-111, `src/graphics/Texture.cpp` decompressed raw PNG assets at runtime using `stbi_load` from `stb_image.h`:
- **CPU Bottleneck:** Runtime software PNG decompression on the PSP's 333 MHz Allegrex CPU took several seconds, blocking game initialization.
- **VRAM / GPU Cache Penalties:** Textures were stored in linear memory layout, bypassing the PSP GPU's 8 KB texture cache, which expects a $16\times 8$-byte block swizzled layout.
- **RAM Bloat:** All textures were stored as 32-bit RGBA8888, wasting MBs of user memory on monochrome or low-color UI icons and terrain ground tiles.
- **Binary Bloat:** `stb_image.h` in `Texture.o` occupied 218 KB of object code.
- **Asset Pipeline Fragmentation:** Assets were split across `data/`, `assets_converted/`, and `assets/`. The existing `convert_assets.py` script was hardcoded, silently cropped textures $>512$, lacked CLI arguments, and did not unpack APK files directly.

## 2. Implemented Offline Pipeline (`tools/convert_assets.py`)
Rebuilt `tools/convert_assets.py` as a complete CLI preprocessor:
- **CLI Options (`argparse`):**
  - `--apk PATH`: Direct extraction and conversion from game APK archive via Python's standard `zipfile` module.
  - `--assets DIR`: Conversion from an existing assets folder.
  - `--out DIR`: Output directory for converted assets (defaults to canonical `assets/`).
  - `--format {5551,8888,auto}`: Target color format (defaults to `auto`).
  - `--no-swizzle`: Optional flag to disable PSP GE block swizzling for debugging.
- **Format Selection Logic (`auto`):**
  - `FORMAT_RGBA8888` (32bpp, 4 B/pixel): High-detail vehicle/character sprites (`Car.png`, `Tire.png`, `driver-body.png`, `driver-head.png`, `antenna.png`, `BridgeWoodBlock.png`).
  - `FORMAT_RGBA5551` (16bpp, 2 B/pixel): Terrain ground and surface textures, HUD icons, pedals, buttons, collectibles (`Coin5..500`, `fuel-canister`), and bitmap fonts.
- **Oversized Textures ($>512$):** Downscaled using high-quality Lanczos resampling with strict aspect ratio preservation ($\text{scale} = 512.0 / \max(W, H)$), completely eliminating silent cropping.
- **PSP Hardware GE Swizzling:** Linear scanlines are permuted into $16\text{ bytes}\times 8\text{ lines}$ blocks with power-of-two padding ($\ge 16\text{ width}, \ge 8\text{ height}, \le 512$).
- **Binary `.tex` Format:** 16-byte `PSPT` header followed by raw swizzled pixel data:
  `[magic 'PSPT' (4B), orig_w (2B), orig_h (2B), pot_w (2B), pot_h (2B), format (2B), swizzled (2B)] + payload`.

## 3. Runtime Texture Loader & PSP Hardware Integration
- **Zero Runtime Decompression on PSP:** `stb_image.h` is completely excluded from PSP builds via `#if !defined(__PSP__)`.
- **DMA-Friendly Aligned Loading:** On PSP, `Texture::LoadTex` reads preprocessed `.tex` directly via single `fread` into 16-byte aligned memory (`memalign(16, payloadSize)`), followed by `sceKernelDcacheWritebackInvalidateAll()`.
- **Hardware Swizzle in `Texture::Bind`:** Configures PSP GPU with texture format and swizzle flag:
  `sceGuTexMode(mFormat, 0, 0, mSwizzled ? 1 : 0);`
  `sceGuTexImage(0, mTextureWidth, mTextureHeight, mTextureWidth, mData);`
  `sceGuTexFunc(GU_TFX_MODULATE, GU_TCC_RGBA);`
- **PC Development & Inspection Fallback:** On PC, `Texture` supports loading `.png` via OpenGL and `.tex` via automatic in-memory deswizzling and 16-to-32-bit pixel expansion for test validation and SDL2 rendering.
- **Canonical Asset Layout:** All code and documentation unified on `assets/`.
  - On PSP, `Texture::Load` transparently maps `.png` paths to `.tex`.
  - Missing asset error prompt in `main.cpp` references only `assets/`.

## 4. Verification & Unit Tests (`tools/test_texture.cpp`)
Implemented regression suite registered in `CMakeLists.txt` and `.github/workflows/build.yml`:
- `TestHeaderPacking`: Validated `sizeof(PSPTexHeader) == 16`.
- `TestSwizzleDeswizzleRoundtrip8888`: Pixel-exact roundtrip verified on $64\times 32$ RGBA8888 buffer (`memcmp == 0`).
- `TestSwizzleDeswizzleRoundtrip5551`: Pixel-exact roundtrip verified on $128\times 64$ RGBA5551 buffer (`memcmp == 0`).
- `TestSyntheticTex8888` & `TestSyntheticTex5551`: Dynamic creation, loading, metadata parsing, UV calculation, and buffer validation.
- `TestRejectionInvalidHeaders`: Clean rejection of non-existent files, corrupt magic (`"NOPE"`), oversized dimensions ($>512$), and truncated payloads.
- `TestExistingAssetsIfPresent`: Validated converted `assets/Car.tex` (256x128 RGBA8888 swizzled, 131,072 B) and `assets/terrain-ground.tex` (512x512 RGBA5551 swizzled, 524,288 B).
- **Result:** All tests pass with zero regressions.

## 5. Measured Telemetry & Hardware Impact

### 5.1 Asset Load Time on PPSSPP (PSP-1000 Hardware Mode @ 333 MHz)
Captured via `sceKernelGetSystemTimeLow()` during automated benchmark in `memstick/PSP/GAME/HCR/perf_snapshot.txt`:
- **UI & Garage Textures (`Game::Init`):** **415.51 ms** (415,514 $\mu$s) for 13 UI textures + BMFont table/texture (eliminated multi-second freeze).
- **Stage Terrain Textures (`Terrain::Terrain`):** **188.08 ms** (188,079 $\mu$s) for 7 textures (`terrain-ground`, `terrain-surface`, `Coin5..500`, `fuel-canister`).
- **Vehicle Textures (`PlayerCar::PlayerCar`):** **66.23 ms** (66,229 $\mu$s) for 4 vehicle textures (`Car`, `Tire`, `driver-body`, `driver-head`).
- **Total In-Game Stage Transition Latency:** **254.31 ms** (instantaneous race start).

### 5.2 Code & Binary Footprint
- `src/graphics/Texture.o`: Reduced from **218 KB** to **24 KB** (**89.0% reduction**).
- Packaged PSP `EBOOT.PBP`: Shrunk from 581,100 bytes to 552,684 bytes (**~28.4 KB saved**).

### 5.3 Memory Savings (RGBA5551 vs RGBA8888)
- `terrain-ground.tex` ($512\times 512$): 512 KB (RGBA5551) vs 1,024 KB (RGBA8888) $\to$ **512 KB saved** per active stage.
- UI Stage Cards ($512\times 256$, 4 stages): 256 KB each vs 512 KB $\to$ **1,024 KB (1 MB) saved**.
- Collectibles & HUD icons ($64\times 64$): 8 KB vs 16 KB each $\to$ **~480 KB saved**.
- **Total Heap Space Reclaimed:** **> 2.0 MB** of user RAM freed on PSP-1000.
