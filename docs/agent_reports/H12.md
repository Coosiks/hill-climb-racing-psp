## 2. Technical Verification

### 2.1 PSP Target (`sceGu`)
In `src/graphics/Renderer2D.cpp` (`#if defined(__PSP__)`):
```cpp
    sceGuDisable(GU_TEXTURE_2D);
    sceGuEnable(GU_BLEND);
    sceGuBlendFunc(GU_ADD, GU_SRC_ALPHA, GU_FIX, 0, 0x00FFFFFF);

    ColorVertex2D* v = (ColorVertex2D*)sceGuGetMemory(4 * sizeof(ColorVertex2D));
    if (v) {
        v[0].color = innerColor; v[0].x = s0x; v[0].y = s0y; v[0].z = 0.0f;
        v[1].color = innerColor; v[1].x = s1x; v[1].y = s1y; v[1].z = 0.0f;
        v[2].color = outerColor; v[2].x = s2x; v[2].y = s2y; v[2].z = 0.0f;
        v[3].color = outerColor; v[3].x = s3x; v[3].y = s3y; v[3].z = 0.0f;

        sceGumDrawArray(GU_TRIANGLE_STRIP, GU_COLOR_8888 | GU_VERTEX_32BITF | GU_TRANSFORM_3D, 4, 0, v);
        sDrawCallCount++;
    }

    sceGuBlendFunc(GU_ADD, GU_SRC_ALPHA, GU_ONE_MINUS_SRC_ALPHA, 0, 0);
    sceGuEnable(GU_TEXTURE_2D);
```
- Additive blending is performed via `GU_FIX` with `0x00FFFFFF` (since `GU_ONE` is not defined in `pspgu.h`).
- The standard alpha blend mode is fully restored: `sceGuBlendFunc(GU_ADD, GU_SRC_ALPHA, GU_ONE_MINUS_SRC_ALPHA, 0, 0)`.
- Texture sampling is restored: `sceGuEnable(GU_TEXTURE_2D)`.
- `GU_BLEND` remains enabled (as initialized in `Renderer2D::Init()`), ensuring subsequent text, UI, HUD, and sprite batches blend properly.

### 2.2 PC OpenGL Target
In `src/graphics/Renderer2D.cpp` (`#else`):
```cpp
    glDisable(GL_TEXTURE_2D);
    glEnable(GL_BLEND);
    glBlendFunc(GL_SRC_ALPHA, GL_ONE);

    glBegin(GL_TRIANGLE_STRIP);
    SetGLColor(innerColor);
    glVertex2f(s0x, s0y);
    glVertex2f(s1x, s1y);
    SetGLColor(outerColor);
    glVertex2f(s2x, s2y);
    glVertex2f(s3x, s3y);
    glEnd();

    glBlendFunc(GL_SRC_ALPHA, GL_ONE_MINUS_SRC_ALPHA);
    glEnable(GL_TEXTURE_2D);
    sDrawCallCount++;
```
- Additive blend mode is set with `glBlendFunc(GL_SRC_ALPHA, GL_ONE)`.
- The standard alpha blend equation is restored: `glBlendFunc(GL_SRC_ALPHA, GL_ONE_MINUS_SRC_ALPHA)`.
- Texture mapping is restored: `glEnable(GL_TEXTURE_2D)`.
- `GL_BLEND` remains enabled throughout.
