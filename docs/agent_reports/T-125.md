## 2. Night Mode Implementation

### 2.1 Configuration
- Added `int is_night` (default 0) to `StageConfig` in `src/core/Config.h`.
- Updated `Config::LoadStages` in `src/core/Config.cpp` to parse `is_night`.
- Covered in `tools/test_config.cpp` (17/17 stage keys tested, 83 total config keys).

### 2.2 Graphics & Shading
- `Renderer2D::DrawLightCone`:
  - Projects trapezoid vertices from Box2D world meters into screen coordinates using camera parameters (`sCameraX`, `sCameraY`, `sCameraZoom`).
  - Takes position `(originX, originY)`, chassis angle `angle`, range `length`, beam start/end widths, and `innerColor` / `outerColor`.
  - Employs additive blending (`GU_ADD, GU_SRC_ALPHA, GU_ONE` on PSP, `glBlendFunc(GL_SRC_ALPHA, GL_ONE)` on PC OpenGL) to illuminate the darkened screen.
- In `src/core/Game.cpp` (`Game::RenderPlaying()`):
  - When `Config::Stages[mCurrentStage].is_night == 1`:
    1. First, `SetupScreenSpace()` and `DrawFilledRect(0, 0, 480, 272, 0xB0080604)` render ambient dark overlay.
    2. Second, `DrawLightCone` is drawn in screen space on top of the ambient darkening, originating at the car headlights (`pos.x + cos(angle)*1.2`, `pos.y + sin(angle)*1.2`) and angled to match chassis pitch.
- **Draw-call and Batch Metrics:** Untextured colored primitives (`DrawFilledRect`, `DrawLightCone`) use the direct color geometry pipeline (1 draw call each, 2 draw calls total), keeping `sBatchedQuadCount = 0` (zero falsification of sprite batch metrics).
