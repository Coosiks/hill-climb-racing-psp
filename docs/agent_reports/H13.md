# H13: Unify Stage Tags Array & Anti-Desync Guard

## 1. Executive Summary
- **Purpose:** Eliminate code duplication and prevent potential out-of-bounds / desynchronization issues between `STAGE_COUNT` and stage string identifier lookups in `PlayerInfo.cpp`.
- **Scope:**
  1. Define a single file-scope `static const char* const kStageTags[]` in `src/core/PlayerInfo.cpp`.
  2. Enforce compile-time parity: `static_assert(sizeof(kStageTags)/sizeof(kStageTags[0]) == STAGE_COUNT, "kStageTags count must match STAGE_COUNT")`.
  3. Replace duplicate local arrays in `SyncToLegacy()` and `SyncFromLegacy()`, adding explicit null guards (`if (!kStageTags[i]) continue;`).
  4. Expose public query method: `static const char* PlayerInfo::StageTagAt(int i)` returning `kStageTags[i]` when $0 \le i < \text{STAGE\_COUNT}$, and `NULL` otherwise.
  5. Add regression Sub-test 9 to `tools/test_save.cpp` validating all stage tags, non-zero hashes, and bounds checking.
  6. Verify binary save layout preservation (`sizeof(SavePayload) == 1556`, `SaveHeader.version == 1`).
- **Status:** Complete. Sub-test 9 passing; 20/20 test suites green.

## 2. Implementation Details

### 2.1 File-scope Declaration & Compile-time Assertion
In `src/core/PlayerInfo.cpp`:
```cpp
static const char* const kStageTags[] = {
    "countryside", "desert", "arctic", "moon",
    "highway", "cave", "mars", "forest",
    "mountain", "mudpool", "volcano", "beach",
    "rollercoaster", "night", "rooftops", "junkyard",
    "construction", "rainbow", "seasons", "bootcamp",
    "xmas", "alienplanet", "arcticcave", "ragnarok"
};
static_assert(sizeof(kStageTags)/sizeof(kStageTags[0]) == STAGE_COUNT, "kStageTags count must match STAGE_COUNT");
```
When `STAGE_COUNT` is modified (e.g. bumped to 28 in T-130), the compiler will immediately reject compilation if `kStageTags` is not simultaneously updated with matching entries.

### 2.2 Public Query API
In `src/core/PlayerInfo.h`:
```cpp
static const char* StageTagAt(int i);
```
In `src/core/PlayerInfo.cpp`:
```cpp
const char* PlayerInfo::StageTagAt(int i) {
    if (i < 0 || i >= STAGE_COUNT) {
        return NULL;
    }
    return kStageTags[i];
}
```

### 2.3 Elimination of Duplicate Arrays and Safe Traversal
Both `PlayerInfo::SyncToLegacy()` and `PlayerInfo::SyncFromLegacy()` previously held local duplicate arrays `const char* stageTags[STAGE_COUNT]`. These were removed, replacing lookups with `kStageTags[i]` and adding safety guards:
```cpp
for (int i = 0; i < STAGE_COUNT; ++i) {
    if (!kStageTags[i]) continue;
    SavedStageEntry* s = GetStageEntry(HashId(kStageTags[i]));
    HighScores[i] = s ? s->bestDistance : 0;
}
```

## 3. Save Layout Invariants
- `HighScores[STAGE_COUNT]` is a runtime-only legacy cache in `PlayerInfo`.
- The binary save payload `SavePayload` contains a fixed array `SavedStageEntry stages[SAVE_MAX_STAGES]` where `SAVE_MAX_STAGES = 64`.
- Struct sizes and alignments remain strictly invariant:
  - `sizeof(SaveHeader) == 16`
  - `sizeof(SavedVehicleEntry) == 12`
  - `sizeof(SavedStageEntry) == 12`
  - `sizeof(SavePayload) == 1556`
  - Version remains `1`.
