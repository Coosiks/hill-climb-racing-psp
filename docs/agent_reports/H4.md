## 1. Context & Reviewer Findings
During external review of Batch 6 (`T-030`, `T-031`), two minor discrepancies were noted:
1. `docs/agent_reports/T-030.md` and `STATUS.md` informally referenced "capacity for up to 32 vehicles and 32 stages", whereas the binary layout in `src/core/PlayerInfo.h` defines:
   $$\text{sizeof}(\text{SavePayload}) = 20 + 64 \times 12 + 64 \times 12 = 1556\text{ bytes}$$
   which actually provides capacity for 64 vehicles and 64 stages (`SAVE_MAX_VEHICLES = 64`, `SAVE_MAX_STAGES = 64`).
2. Although `#pragma pack(push, 1)` is maintained for bit-exact serialization between 64-bit PC and 32-bit PSP MIPS, the 4-byte offset invariant protecting against hardware Address Error Exceptions on MIPS Allegrex lacked automated `offsetof` compile-time assertions.

---

## 2. Implemented Changes

### 2.1 Compile-Time Field Offset Invariants (`src/core/PlayerInfo.h`)
Added explicit `offsetof` compile-time checks using `<cstddef>` / `<stddef.h>`:
```cpp
// MIPS Allegrex 4-byte natural alignment assertions.
// On PSP (MIPS R4000 derivative), unaligned 32-bit reads/writes trigger hardware Address Error Exceptions.
// Explicit padding ensures all 32-bit fields reside at offsets divisible by 4.
static_assert(offsetof(SavedVehicleEntry, idHash) % 4 == 0, "MIPS alignment");
static_assert(offsetof(SavedStageEntry, idHash) % 4 == 0, "MIPS alignment");
static_assert(offsetof(SavedStageEntry, bestDistance) % 4 == 0, "MIPS alignment");
static_assert(offsetof(SavePayload, vehicles) % 4 == 0, "MIPS alignment");
static_assert(offsetof(SavePayload, stages) % 4 == 0, "MIPS alignment");
```

### 2.2 Unaligned Buffer Deserialization Verification (`tools/test_save.cpp`)
Implemented **Sub-test 7** in `tools/test_save.cpp`:
- Allocated an aligned buffer `alignas(4) uint8_t rawBuf[sizeof(SaveFile) + 4];`.
- Placed serialized save image at an intentionally unaligned offset `rawBuf + 1` (where `(uintptr_t)ptr % 4 != 0`).
- Verified that reading the unaligned image into aligned stack structures via `memcpy` succeeds bit-exact without hardware faults or data corruption.

### 2.3 Documentation Corrections
- Updated `docs/agent_reports/T-030.md` and `docs/STATUS.md` to reflect the authentic payload capacity: 64 vehicles and 64 stages (1556 bytes).
