## Installation & Quick Start

### Sony PlayStation Portable (PSP) / PPSSPP
1. Extract `hcr-psp-v0.1.0-beta.2.zip` to your computer.
2. Copy the `PSP` folder to the root of your Memory Stick (`ms0:/PSP/GAME/HCR/EBOOT.PBP`).
3. Extract assets from your legally owned APK using:
   ```bash
   python3 tools/convert_assets.py --apk path/to/hcr-1.30.0.apk --out ms0:/PSP/GAME/HCR/assets/
   ```
4. Launch from the PSP XMB under Game $\to$ Memory Stick.

### Linux PC
1. Extract `hcr-pc-v0.1.0-beta.2-linux.tar.gz`.
2. Convert assets into the `assets/` directory next to the executable.
3. Install SDL2 runtime:
   ```bash
   sudo apt-get install -y libsdl2-2.0-0 libgl1-mesa-glx
   ```
4. Run `./hcr_pc`.

## 4. Bridge Gating Audit in `Terrain.cpp`

In `src/physics/Terrain.cpp`:
1. Gated caller in `AdvanceGeneration`:
   ```cpp
   if (mStageConfig && mStageConfig->has_bridges == 1) {
       MaybeSpawnBridge(slotIdx);
   }
   ```
2. Gated callee in `MaybeSpawnBridge`:
   ```cpp
   void Terrain::MaybeSpawnBridge(int slotIdx) {
       if (!mStageConfig || mStageConfig->has_bridges == 0) {
           return;
       }
       TerrainChunk& chunk = mChunks[slotIdx];
       if (chunk.chunkIndex > 0 && (chunk.chunkIndex % 4 == 1)) {
           // Create bridge over chasm
       }
   }
   ```
This provides 100% defense-in-depth: regardless of whether `MaybeSpawnBridge` is called internally by terrain generation or external callers, bridges are strictly prohibited from spawning on stages where `has_bridges == 0`.
