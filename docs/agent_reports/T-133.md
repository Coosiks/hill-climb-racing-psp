# Task Report: T-133 — Pause State & Distance Bonus Coins

## 1. Summary of Implementations
This task introduces the dedicated `STATE_PAUSE` state machine mode and the distance bonus milestone reward system, fulfilling core gameplay parity requirements with Hill Climb Racing v1.30.0.

### 1.1 Pause State (`STATE_PAUSE`)
- **State Transition:**
  - Enter `STATE_PAUSE` by pressing `PSP_CTRL_START` during active gameplay (`STATE_PLAYING`).
  - Toggle exit (Resume) with `PSP_CTRL_START` or `PSP_CTRL_CIRCLE`.
- **Simulation Invariants During Pause:**
  - Physics simulation is frozen: accumulator is zeroed (`mAccumulator = 0.0f`).
  - Vehicle linear velocity, angular velocity, and position remain completely unchanged across any number of frames.
  - Driver inputs (throttle, brake, thruster) are suspended and not applied to Box2D bodies.
  - Audio Engine pauses all audio streams and engine sound loops (`AudioEngine::PauseAll()`).
  - Upon unpausing, `mLastTime` is re-synchronized to current wall-clock time, preventing physics time deltas or accumulator spikes.
- **Pause Menu Options:**
  - `0: RESUME`: resumes race simulation, re-enables inputs, and unpauses audio.
  - `1: RESTART`: unpauses audio, cleanly ends race, and re-invokes `StartRace()` on the current stage/vehicle.
  - `2: GARAGE`: unpauses audio, stops stage music, cleanly ends race, and returns to `STATE_GARAGE`.
- **Zero-Alloc Visual Presentation:**
  - Screen-space frozen rendering of current race background via `RenderPlaying()`.
  - Semi-transparent full-screen darkening (`0x88000000`).
  - Centered dialog box with highlighted active selection and button hints rendered using `Renderer2D` and `mFont`.

### 1.2 Distance Bonus Coins System
- **Configuration & Integration:**
  - Parameters added to `config/physics.cfg` under `[rules]`:
    - `distance_bonus_step = 100.0` (interval in meters)
    - `distance_bonus_coins = 500` (coins awarded per interval)
  - Registered in `src/core/Config.h`, `Config.cpp`, `docs/params.csv`, and covered in `tools/test_config.cpp` (23/23 keys in `physics.cfg`, 96 total keys).
- **Runtime Milestone Tracking:**
  - As `pos.x` advances beyond previous `mMaxDistance`, milestone steps crossed are computed:
    ```cpp
    int oldStepIdx = (int)(mMaxDistance / step);
    mMaxDistance = pos.x;
    int newStepIdx = (int)(mMaxDistance / step);
    if (newStepIdx > oldStepIdx) {
        int added = (newStepIdx - oldStepIdx) * coinsPerStep;
        mRaceDistanceBonusCoins += added;
        mSessionCoins += added;
        AudioEngine::PlaySFX(SFX_COIN);
    }
    ```
  - Bonus is displayed on the results screen with `DISTANCE BONUS: +%d`.
  - Included in total session earnings (`mSessionCoins = mRaceCollectedCoins + mRaceTrickBonusCoins + mRaceDistanceBonusCoins`) and atomically committed to `PlayerInfo` on game over.
