# Task Report: H16 — Audio Routing Fix & Sleigh Atlas Extraction Refinement

## 1. Problem Statement & Findings
1. **Audio Volume Routing Flaw:**
   - In both PSP (`AudioThread`) and PC (`AudioCallback`), `volFactor` for the synthesized vehicle engine loop was computed as `(int)(mMusicVolume * 180.0f)`.
   - Engine motor noise is a core gameplay sound effect (SFX) that belongs to the SFX channel and must strictly follow `mSFXVolume`.
   - `mMusicVolume` was improperly attenuating or boosting the engine sound, while having no effect on any music channel.
2. **Sleigh Frame Atlas Extraction:**
   - In `tools/convert_assets.py`, `extract_sleigh_sprite_from_atlas` selected the first dictionary key containing `"sleigh"`.
   - If an atlas contained multiple sub-frames (e.g., runners, skis, reindeer parts, or decorators), picking the first match could inadvertently select a non-chassis component.
   - Also, Cocos2d format 3 uses `spriteOffset` / `offset` rather than `sourceColorRect`.

## 2. Changes Implemented

### 2.1 Audio Engine Routing
- Fixed both PSP and PC callbacks to scale `volFactor` strictly by `mSFXVolume`:
  ```cpp
  int volFactor = (int)(mSFXVolume * 180.0f);
  ```
- Formalized and documented the invariant in `src/audio/AudioEngine.h`:
  ```cpp
  // INVARIANT: mMusicVolume scales ONLY the streaming background music channel.
  // Motor sound, vehicles SFX, and UI clicks/coins scale strictly with mSFXVolume.
  static void SetMusicVolume(float vol);
  static void SetSFXVolume(float vol);
  static float GetMusicVolume();
  static float GetSFXVolume();
  ```

### 2.2 Sleigh Atlas Extraction Refinement
- Added logging of all candidate frame keys from `atlas/sleigh.plist`.
- Implemented scoring heuristic with explicit chassis priority:
  - Candidates with `sleigh` + (`small`, `body`, `chassis`, `hull`) receive highest priority.
  - Non-chassis components (`reindeer`, `circle`, `runner`, `ski`, `leg`) are heavily penalized.
- Added support for `spriteOffset` / `offset` (Cocos2d format 3 / format 2) fallback centering calculation:
  ```python
  paste_x = (sw - fw) // 2 + ox
  paste_y = (sh - fh) // 2 - oy
  ```
