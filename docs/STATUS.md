## Сломано / не реализовано
- **Статический пул аллокаций Box2D:** Box2D пока использует базовый `malloc`/`free` вместо фиксированного статического пула (задача T-010).
- **Чанковая система трассы:** Физика земли сейчас генерируется одним монолитным буфером, что ограничивает дистанцию без перезагрузки (задача T-020).
- **Динамический мост:** Доски моста на joint-соединениях ещё не добавлены (задача T-022).
- **Звуковой движок `sceSas`:** Аудио воспроизводится через `sceAudio`, прямой синтез через голоса `sceSas` для экономии тактов CPU планируется в T-043.
- **Атлас спрайтов и батчинг:** Рендер пока выполняет индивидуальные draw calls для каждого спрайта (задача T-040).
